## Why Surf Skills

Most skill directories show you a name and a description. Surf Skills shows you the output. Every skill comes with a short video of a real run, so you can judge it before you install it. All skills are open source and work with the agent you already use.

## How a skill gets here

A new skill goes live every day. Each one comes out of the same six-step pipeline, run by AI agents, with checks at every step:

1. **Pick.** Find a trending open-source skill that hasn't been featured yet.
2. **Plan.** Design one short, real demo task and decide how to check the result.
3. **Run.** Run the skill on that task in a locked-down sandbox. Code and a separate AI reviewer check the output.
4. **Card.** Write the page: what the skill does, when to use it, and an FAQ.
5. **Video.** Turn the real result into an 11-second preview. A reviewer AI must pass it, or the skill is dropped.
6. **Publish.** Schedule the card for its own day. It goes live at midnight on that day.

The pipeline stops at the first problem instead of patching around it.
